## About project

TaskBoard allows creating tasks, assigning statuses, and tracking progress.
The project will be developed step-by-step during the course.

## Technologies

| Layer | Technologies |
|---|---|
| Frontend | HTML, CSS, JavaScript |
| Backend | Python, Flask *(planned)* |
| Database | SQLAlchemy, PostgreSQL *(planned)* |
| Deployment | Docker *(planned)* |

## How to run

1. Clone the repository if you do not already have a local copy:
```bash
git clone https://github.com/kudriavtsevmdipz24-alt/taskboard.git
```
2. Open the folder in VS Code.
3. Run `index.html` with Live Server.

## W-07. Сторінка «Про автора»

На головній сторінці є опис TaskBoard. У меню «Про автора» відкривається профіль із навичками, планом навчання й контактами. З головної також можна відкрити сторінку з матеріалами про HTML.

Під час здачі відкрий обидві основні сторінки в браузері. У DevTools (`F12`, вкладка **Elements**) покажи `header`, `nav`, `main` і `footer`. Короткий звіт міститься в [docs/report.md](docs/report.md#w-07-сторінка-про-автора).
