## About project

TaskBoard allows creating tasks, assigning statuses, and tracking progress.
The project will be developed step-by-step during the course.

## Technologies

| Layer | Technologies |
|---|---|
| Frontend | HTML, CSS, JavaScript |
| Backend | Python, Flask *(planned)* |
| Database | SQLAlchemy, PostgreSQL *(planned)* |
| Deployment | Docker *(planned)* |

## Development roadmap

- [x] Repository and first page

- [ ] Docker
- [ ] REST API and tests

## How to run

1. Clone repository:
```bash
git clone https://github.com/kudriavtsevmdipz24-alt/taskboard.git
```
2. Open the folder in VS Code.
3. Run `index.html` with Live Server.
